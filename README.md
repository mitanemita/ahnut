# Ахнуть — «Открытка, от которой ахнут»

Сервис персональных ИИ-открыток в подарок.

| Этап | Статус |
|---|---|
| 1. Скелет: Docker Compose, Caddy, Postgres, n8n | готово |
| 2. Оплата ЮKassa, заказы, «без оплаты генерации нет» | готово (проверено на поддельном API ЮKassa) |
| 3. Библиотека блоков + 7 шаблонов «Записки» | готово, демо: `/demo/<шаблон>` |
| 4. Анкеты и генерация всех тарифов: «Записка», «Свидание», «Принц» | готово (нейросеть — подделкой, см. ниже) |
| 5. Правки (2 + докупка), публикация, ссылка, пароль, файл, сроки, продление, письма | готово (письма — UniOne, без ключа пишутся в лог) |
| 6. (сделано в 4) · 7. Лендинг с примерами · 8. Юр. страницы и модерация · 9. Аналитика | черновики оферты и политики — `/offer`, `/privacy` |

## После оплаты

- `/order/<id>` — страница отправителя (по ней можно править и продлевать, получателю не отправлять).
- Правки: 2 входят в тариф, пакеты 1 и 3 правки докупаются (`EDIT_PACKS` в `app/catalog.py`). Неудачная правка не
  списывается, любую прошлую версию можно вернуть бесплатно.
- Публикация → `/c/<card_id>` (отдельный случайный id, опционально пароль) + файл HTML. Ссылка живёт 7 дней,
  продление: месяц 149 ₽, год 490 ₽, навсегда 990 ₽. За сутки до конца — письмо.
- Деньги не возвращаются; если генерация не удалась — бесплатный повтор (кнопка на странице заказа).
- Через 30 дней после окончания срока фото, музыка, анкета и тексты открытки удаляются автоматически.
  По запросу: `docker compose exec web python -m app.admin purge <id-заказа | email>`.

## Тарифы

| | Анкета | Фото | Что делает нейросеть |
|---|---|---|---|
| «Записка» | 10 кнопками + 2 текстом | 1–4 | заполняет готовый шаблон текстами, фото не видит |
| «Свидание» | ~20 кнопками + 5 текстом | 1–7 | собирает открытку из библиотеки блоков, смотрит фото и подписывает их |
| «Принц» | ~30 кнопками + 10 текстом, референсы, своя музыка | 1–15 | библиотека + до 3 своих сцен (HTML/CSS/JS) + самопроверка в браузере по скриншотам на 375px и исправление |

Свои блоки «Принца» проверяются до показа: запрещены сеть, внешние ссылки, хранилища, eval; страница открытки
отдаётся с CSP `connect-src 'none'`, предпросмотр — в iframe.

## Как устроена открытка

Нейросеть отдаёт **JSON** (`app/cards/spec.py`), сервер собирает HTML из проверенных блоков
(`app/cards/assets/`), интерактив — `card.js` (ползунок тянется пальцем, «нет» убегает, частицы, бутоны
растут от нажатий). Романтика (сцена «пара», кольцо) вырезается сервером для любого получателя,
кроме второй половинки, даже если её вернула модель.

Блоки: конверт, заголовок, телефон-галерея, полароиды, карточки-предметы, письмо, викторина,
хронология, «N причин», свой блок («Принц»), финальная сцена, подпись. Примеры «Свидания» и «Принца» —
`app/cards/examples/` (`/demo/svidanie_friend`, `/demo/prince_anniversary`).

- `app/cards/presets/*.json` — шаблоны «Записки» (что в них менять — тексты, значки, акценты)
- `app/cards/icons.py`, `scenes.py`, `themes.py` — значки, финальные сцены, темы
- `app/pipeline.py` — промт и проверка ответа модели; `app/llm.py` — единственная точка доступа к модели

## Стек и почему он

- **Python 3.12 + FastAPI + Jinja2 + SQLAlchemy 2 (async) + Alembic + Postgres** — тот же стек, что
  во втором проекте (`dubrovskiy_arenda`): один набор привычек, команд и деплоя на двоих.
  Страницы рендерятся на сервере, интерактив анкеты на небольшом ванильном JS, без отдельного
  фронтенд-проекта и сборщика: меньше всего, что придётся поддерживать в одиночку.
- **Сборка открыток**: Jinja-шаблоны блоков + JSON от нейросети → HTML + `card.js`. Самопроверка по
  скриншоту на 375px — Playwright для Python, браузер в отдельном сервисе `browser`.
- **n8n** — конвейер генерации. Вебхук ЮKassa принимает `web`, проверяет платёж запросом к API
  ЮKassa и только после этого вызывает n8n внутри Docker-сети. Наружу n8n открыт лишь своим
  интерфейсом (`n8n.ahnut.ru`, вход по учётной записи владельца).
- **Caddy** — сам получает и продлевает сертификаты, конфиг на 20 строк.

## Сервисы (`docker-compose.yml`)

| Сервис | Что делает |
|---|---|
| `caddy` | 80/443, HTTPS, `www` и `ахнуть.рф` → редирект на `ahnut.ru` |
| `db` | Postgres 17; при первом старте создаёт отдельную базу `n8n` (`db/init/`) |
| `migrate` | `alembic upgrade head`, затем завершается |
| `web` | сайт; фото и файлы открыток — в томе Docker `files` на диске сервера |
| `browser` | Chromium (Playwright server) для самопроверки «Принца» по скриншотам |
| `n8n` | оркестратор, хранит данные в Postgres |

## Запуск на сервере

```bash
cp .env.example .env    # заполнить пароли: openssl rand -hex 24
./deploy.sh
```

До запуска в DNS нужны A-записи на IP сервера: `ahnut.ru`, `www.ahnut.ru`, `n8n.ahnut.ru`,
`ахнуть.рф`, `www.ахнуть.рф`. Без них Caddy не получит сертификаты.

Локально без доменов: в `.env` раскомментировать блок «Локальный запуск», открыть
`http://localhost` и `http://n8n.localhost`.

## Разработка без ключей

`LLM_FAKE=true` — «нейросеть» без сети подставляет ответы анкеты в шаблон (оплату не обходит).
Без `N8N_GENERATE_URL` генерация запускается прямо в web. Демо-шаблоны: `/demo/mom_birthday` и т.д.
